Earth Trend Explorer — System Architecture

The browser dashboard requests annual global temperature data from a small Python FastAPI bridge. The bridge retrieves NASA GISTEMP v4, keeps complete annual values, and caches the response for one hour. No live FIRMS, OCO-2, sea-level, or sea-ice feed is connected in this prototype. 

Browser dashboard
  └─ GET /api/temperature
       └─ FastAPI bridge
            └─ NASA GISTEMP v4 global-means CSV
                 └─ annual J-D column; incomplete years skipped

GET /api/health reports whether a response is cached.
CO₂, sea level, sea ice, fire, regional values and map shading are demos.
